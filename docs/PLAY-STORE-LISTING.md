# Google Play listing draft — MARS-X Pool Beta

## App name

MARS-X Pool Beta

## Short description

Monitor authorised remote workers and test pool-management workflows safely.

## Full description

MARS-X Pool Beta is a closed-test remote worker and pool-management client.

Use it to connect an authorised worker, check the service connection, register the worker, send a manual heartbeat and test a clearly labelled sandbox balance and payout-request workflow.

The Android application does not mine cryptocurrency on your phone, run hidden background computation or use your device resources for third-party work. `USDT_TEST` is a simulation unit: it is not real money, cannot be withdrawn and does not represent promised income.

Closed-beta features:

- HTTPS service-health check
- Device-bound beta or Google Play subscription session
- Explicit worker registration and manual heartbeat
- Persistent server-side worker status
- Sandbox balance and payout-request history
- English, Turkish, Indonesian and Arabic interface
- Built-in test checklist and feedback sharing

Mining output, uptime, profitability, token value and cost recovery are never guaranteed. Connect only devices and accounts you own or are authorised to manage.

## Review-team access note

This build is a remote-management and sandbox-accounting beta. It performs no on-device mining. Provide Google Play review with one active one-device beta licence, the production HTTPS endpoint and these steps:

1. Accept the licence/privacy summary.
2. Activate the supplied beta licence.
3. Register the test worker.
4. Send a heartbeat.
5. Refresh `USDT_TEST` balance and payout history.

No real crypto transfer is possible in this build.
