MARS-X Pool Privacy Policy

Last updated: 23 October 2026.

MARS-X Network DEMO (versionCode 18)

The Network DEMO launcher is a local demonstration. Real third-party bandwidth sharing, partner traffic forwarding, mining, real earnings, payouts and transfers are disabled. Network consent is an optional local test preference and can be withdrawn using the same consent control. The monitor measures only this app's traffic. Session statistics, language choice and any public wallet address entered are stored on the device; entering an address does not initiate a transfer or share wallet credentials.

Optional test advertising and Google consent

Version 18 includes Google Mobile Ads and Google's User Messaging Platform (UMP). Advertising is initially off. The separate test-ad button contacts Google to update privacy choices and display any required consent message. An ad request is made only after a successful update and UMP authorization. Network consent does not authorize advertising. The DEMO uses Google's test banner, does not monetize impressions, and does not grant rewards or withdrawable credit. The Network launcher does not initialize Qonversion or expose purchases.

When users choose to enable advertising, Google may collect and share the connection IP address (including approximate location inferred from IP), app/ad interactions, diagnostic information and device/app identifiers for advertising, analytics and fraud prevention. The Android advertising-ID and AdServices permissions are removed from the DEMO manifest; this does not eliminate all other identifiers or connection data. Advertising SDK traffic is encrypted in transit using TLS. MARS-X does not receive advertising profiles or sell personal information. Google's handling and retention are governed by its privacy policy and applicable advertising settings; MARS-X does not promise a specific Google retention period.

Users can stop displaying/requesting ads with the in-app off control and open advertising privacy options where UMP requires them. Turning ads off does not retract data already transmitted. Local DEMO preferences, session history and saved public wallet addresses can be removed by clearing this app's storage or uninstalling it. For privacy requests, use the contact below. Legacy Pool account data can be deleted through the existing account-deletion page; this separate account workflow does not imply that the Network DEMO creates an account.

Legacy Pool versions

Legacy MARS-X Pool Beta is an authorised remote node/pool management and sandbox-payout test. It does not mine cryptocurrency on the Android device, run hidden background compute, promise earnings, or transfer real money in sandbox mode.

Data processed

After an explicit action, the service receives a random installation/worker ID, Google account subject identifier, verified email and display name, licence or subscription status, optional one-level referral relationship, app/platform version, request time, sandbox balance activity and security logs. The Google subject is stored only as a keyed hash. Qonversion and Google Play process subscription data; Supabase processes API requests and stores service records in PostgreSQL. Payment-card data is not received by MARS-X.

Purpose, retention and rights

Data is used to authenticate accounts, protect licences, operate the beta, calculate the disclosed referral share, prevent abuse and troubleshoot faults. The app provides an account-deletion action that deletes the MARS-X account, linked worker records, profile, active sessions, referral records and sandbox activity associated with that account. Users who no longer have the app can start the same request from the account deletion page. MARS-X does not sell personal data; the optional advertising disclosure above applies to Network DEMO versions. Users in France may complain to the CNIL.
