# Integration note

The Kotlin JVM module can be tested with `gradle test` from `network-sandbox/` when Gradle and JDK 17 are installed. No Gradle wrapper is committed; CI must provision Gradle explicitly.

IMPORTANT: `SandboxEngine` currently accepts a boolean mock receipt; this is intentionally test-only and must never be exposed to Android users as real earnings. The separate `NetworkPolicy` class adds opt-in and cellular/roaming controls but has not yet been wired to the engine.

Next implementation: use one authoritative policy check before every locally simulated test, then add Android UI and instrumentation. Do not add residential proxy routing before policy/legal/partner review.
